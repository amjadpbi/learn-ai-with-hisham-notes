# Learn AI with Hisham — Class Notes Library

Handwritten-style notebook notes for the 9-class "Learn AI with Hisham" series
by Hisham Sarwar, 12 to 26 Oct 2026.

Each class has:
- 4 notebook pages (in `assets/`)
- Short key points on the webpage
- A link to the original Facebook class video
- A full auto-generated transcript in `transcripts/` (5-minute timestamped blocks)

Notes are important-points summaries, not a verbatim transcript or a
click-by-click manual. Transcripts are auto-generated and unedited.

Open `index.html` (or the GitHub Pages site for this repo) to browse
all 9 classes in order.
